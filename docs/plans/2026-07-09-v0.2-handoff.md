## 주의사항 (구현 컨텍스트)

- **mpv 프로퍼티는 화이트리스트 필수** — `electron/mpv-controller.js`의
  `ALLOWED_SET_PROPS`/`ALLOWED_GET_PROPS`에 없으면 IPC에서 거부됨
- **preload 확장 시 3단 세트**: `electron/preload.js` + `src/types/global.d.ts` + 핸들러
- 단축키 추가 시 `HelpModal.tsx` SECTIONS 등재, 문자 키는 `e.code` (IME-안전)
- localStorage 키: `offcut.player.{recent,secret,captureFormat,accent,playMode,positions}`
- `sub-delay`/`audio-delay`는 파일 전환 후에도 유지됨(의도 — 같은 릴리즈 그룹 연속 시청).
  회전/비율/줌만 파일 전환 시 리셋
- dev 스모크 테스트 시 `ELECTRON_RUN_AS_NODE=1`이 사용자 셸에 있음 —
  `electron-launcher.js`가 strip 처리 (직접 `npx electron .` 실행 금지)
